# Security and responsible use

Murphy provides observation and investigation support. It is not an enforcement product, a human-approval authority or a guarantee that an endpoint is safe.

Deep Audit may require Windows elevation. Enable it deliberately on a machine you control. No permanent service or driver is required by this version.

Task context is cooperative input from an enabled integration. It is not authenticated human authorization. Independent endpoint observations and contextual interpretation serve different purposes.

A normal state is not proof that nothing unexpected happened. Review and Attention request investigation; neither establishes malicious intent or completed data transmission.

## Reporting a concern

Do not place credentials, personal paths, raw reports, exploit details or runtime evidence in public issues. A dedicated private disclosure channel has not yet been published here. Until one is available, do not submit sensitive security material to this public repository.

This repository contains presentation materials only. No independent third-party audit certification is claimed by these documents.
