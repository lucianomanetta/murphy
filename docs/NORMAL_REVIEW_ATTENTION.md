# Normal, Review and Attention

| State | Meaning | Suggested response |
| --- | --- | --- |
| Normal / blue | No pending review requirement is presented for the observed activity. | Continue observing; this is not proof of safety or complete coverage. |
| Review / yellow | An observed pattern merits checking in context. | Open the evidence and decide whether the activity was expected. |
| Attention / red | A pattern has been escalated for closer attention. | Inspect the involved resource, context and supporting observations. |

Marking an item as reviewed acknowledges it; it does not change the observed operation into a success or authorize future activity. The overall state depends on the remaining pending items.

An agent's Active / Background presence state is separate from these review states. Unexpected activity is also not automatically a threat.

Always distinguish a request from completion and correlation from causality.
