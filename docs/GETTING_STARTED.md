# Getting started

This repository does not yet distribute Murphy binaries. These instructions describe the current Windows product for users who already have an authorized package.

1. Exit an older Murphy instance before opening the current package. Keep the supplied application files together in a private writable location.
2. Open Murphy. Standard monitoring starts automatically for supported process and network observations.
3. Use Overview to inspect recognized agents and Activity to investigate observations.
4. Enable Deep Audit in Settings when file-request visibility is needed, and review the Windows elevation prompt.
5. Enable a supported task-context integration if desired. Confirm its status before relying on received context; manual workspace entry is optional.
6. In Activity, choose **Export technical report (.md)** to export while monitoring continues. Inspect the report's cutoff and coverage bounds.
7. Use **Mark as reviewed** after investigating a pending finding. **Exit Murphy** closes the application completely.

Settings → Language supports English (United States) and Português (Brasil). The choice is stored locally.

Read [privacy](../PRIVACY.md) and [limitations](../KNOWN_LIMITATIONS.md) before sharing reports or interpreting an alert.
